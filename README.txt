SMART CALCULATION UTILITY
=========================

Files:
- main.py: menu and user interaction
- utility_package/__init__.py: makes the folder an importable Python package
- utility_package/calculations.py: reusable calculation functions

How to run on Windows:
1. Extract the ZIP file.
2. Open the extracted SmartCalculationUtility folder.
3. Click the address bar in File Explorer, type cmd, and press Enter.
4. Run: python main.py
   If that does not work, run: py main.py

Important:
Keep main.py and the utility_package folder together.
