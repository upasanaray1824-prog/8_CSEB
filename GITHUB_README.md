# Smart Calculation Utility — Group 8

IT Workshop (Python) mini project.

## Project files
- `main.py` — menu and user interaction
- `utility_package/__init__.py` — package exports
- `utility_package/calculations.py` — reusable calculation functions
- `Group 8_CSE B_IT WORKSHOP MINI PROJECT.pdf` — project report

## Run
Open a terminal in this folder and run:

```bash
python main.py
```

Python 3 is required. The project uses only Python's built-in `math` and `random` modules.
